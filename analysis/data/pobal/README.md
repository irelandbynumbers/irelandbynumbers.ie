# Pobal childcare fees

Typed in by hand from Pobal's Annual Early Years Sector Profile reports, which
Pobal published each year until 2020/21. From 2021/22 the reports were replaced
by online dashboards (pobal.ie/EarlyLearningandChildcaredata) that offer no
download, so there are no later figures here. Fees have been capped at their
September 2021 level for services in Core Funding since September 2022.

- `fees_national.csv`: average weekly fee per child, by type of care. The
  `report` column gives the table each row was taken from.
- `fees_by_county_2020_21.csv`: average weekly fee by county or council area,
  2020/21, from Table 6.3 of the 2020/21 report (the same table was given in a
  Dáil written answer in May 2024).

Pobal's averages are the average across services of each service's median fee.
