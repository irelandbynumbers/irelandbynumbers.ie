# Ireland by Numbers

Source for [irelandbynumbers.ie](https://irelandbynumbers.ie), official Irish statistics in clear, interactive charts and maps.

Built with [Quarto](https://quarto.org). Every push to `main` builds the site and publishes it to the `gh-pages` branch, and every pull request is checked to make sure the site still builds. Preview locally with `quarto preview`.

## How a chart is made

Each topic has a script, `analysis/<topic>/make_charts.py`, with a `build()` function that fetches its data, draws each chart with Plotly and writes it with `ibn.chart.Chart`:

```python
from ibn import cso, figures
from ibn.chart import Chart, Source

def build():
    df = cso.fetch("PEA01")          # saved to analysis/data/cso/PEA01.csv
    ...
    Chart(id="population-total", topic="population",
          title="...", subtitle="...",
          sources=[Source.cso("PEA01", "Population Estimates")],
          notes=["How the figure is measured, and any breaks in the series."],
          key_fact=f"An estimated {millions(last)} people lived in the State in April {year}.",
          data=rows_as_plotted, figure=figures.lines(...)).write()
```

`key_fact` is one plain sentence worked out from the data, so it stays current when the data is refreshed. Topic pages list them with `{{< key-facts <id> <id> ... >}}`.

That writes `charts/<id>.html` (the chart's own page, with its source and notes, a table view, PNG and CSV downloads and an embed code), `charts/<id>.csv`, and an entry in `charts/index.json`. A topic page shows the chart with `{{< chart <id> >}}`.

```sh
pip install -r analysis/requirements.txt
python3 analysis/build.py              # rebuild every chart from the saved data
python3 analysis/build.py --refresh    # fetch the latest data first
python3 analysis/build.py housing      # one topic
python3 tools/cso_find.py search "dwelling completions"   # find a CSO table
quarto preview
```

`analysis/ibn/` holds the shared parts: `style.py` (colours and layout, shared with [Fianaise](https://github.com/fianaise/fianaise.ie)), `figures.py` (line charts and county maps with a time slider), `cso.py` (fetching CSO tables) and `chart.py` (the chart page). Each chart page also shows when its source was last updated by the publisher and when it was last checked (from `analysis/data/cso/_dates.json`, written whenever a table is fetched), links to the original table, and has a Share link button. `node tools/thumbnails.js` draws the tile thumbnails in `images/charts/` and the link preview images in `images/social/`.

The weekly publish run fetches the latest data, rebuilds every chart, county page and image, and commits the changes.

## Regular content

- Chart of the week: add an entry at the top of `chart-of-the-week.yml`. The homepage shows the newest, and `chart-of-the-week.qmd` lists them all.
- What's new: add a dated line to `whats-new.qmd`. The table of source update dates under it is generated.
- Corrections: add every correction to `corrections.qmd`.
- Irish titles and summaries for each topic are in `irish.yml`, and appear on the topic pages once `approved: true` is set.
- County pages (`counties/*.qmd`) are generated by `analysis/counties/make_charts.py`, so edit the script rather than the pages.

## Layout

The homepage shows each topic as a tile, from `topics.yml`, with a thumbnail from `images/topic-*.svg` (drawn by `tools/make_topic_images.py`). Each topic folder has an `index.qmd` that shows its subtopics as tiles, from the folder's `pages.yml`, and one page per subtopic (for example `population/growth.qmd`) that holds the charts. Subtopic tiles use a thumbnail of one of their charts, made by `node tools/thumbnails.js` into `images/charts/`.

A new topic needs an entry in `topics.yml`, a folder with `index.qmd` and `pages.yml`, a thumbnail, and a line in the navbar in `_quarto.yml`.

## Writing style

Plain, neutral sentences that state what the data shows. No first person, few colons, and bold or bullet points only where they help. Titles without commas, for example "Housing in numbers".

## Domains

`CNAME` points GitHub Pages at irelandbynumbers.ie. irelandbynumbers.org forwards to it from a separate repository, `irelandbynumbers/irelandbynumbers.org`, that holds only a redirect page.

DNS for irelandbynumbers.ie is four A records for `@` pointing to 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153, and a CNAME for `www` pointing to irelandbynumbers.github.io.
